# CSE 535 F26 - Project 2

Group 11 Android starter app.

## Build and run

1. Open the project in Android Studio.
2. Use Gradle JDK 17 or 21 and install SDK Platform 36 / Build Tools 35.0.0.
3. Sync Gradle, then run `app` on an API 29+ emulator or device.
